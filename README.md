# 叠图 · 本地 UI 对比

一个无需构建、无需账号的 Chrome 扩展。选择本地设计图，将它叠加到当前网页上，检查布局、间距、字体和视觉还原程度。适合 localhost 开发页面，也支持普通网站。

## 安装

1. 在 Chrome 地址栏打开 `chrome://extensions`。
2. 打开右上角的「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择本项目目录，也就是包含 `manifest.json` 的文件夹。
4. 点击浏览器工具栏的扩展拼图图标，把「叠图 · 本地 UI 对比」固定到工具栏。

无需运行 npm、安装依赖或启动服务器。

## 使用

1. 打开要对比的网页，点击扩展图标。
2. 点击「选择一张设计图」，或者将图片拖进扩展弹窗。
3. 调整不透明度，通常 50% 方便观察轮廓是否重合。
4. 关闭弹窗，直接拖动网页上的设计图。选中图片后，方向键每次移动 1 px，Shift + 方向键每次移动 10 px。
5. 对齐后开启「锁定位置，穿透点击」，或按 Esc 锁定，即可点击、滚动和操作下方网页。网页右下角工具条可以随时解锁。
6. 长设计稿开启「跟随页面滚动」。关闭时，图片固定在浏览器视口；开启时，图片锚定网页坐标并跟随滚动。
7. 隐藏图片后，再次点击扩展图标并打开「显示图片」即可恢复。

支持不透明度 0–100%、缩放 10–300%、X/Y 坐标输入、原始尺寸、适应窗口、居中、归零、重置和移除。适应窗口受最低 10% 缩放限制，超长图片可开启跟随页面滚动检查。

## 本地保存与权限

- 图片通过浏览器 File API 读取，不发送到网络，不使用云端或同步存储。
- 只在本机 IndexedDB 中保存最近一次选择的图片，便于下次点击「使用上次保存的图片」。调整参数保存在 `chrome.storage.local` 中。
- 每个标签页的叠图独立运行。页面刷新或导航会清除当前页面的叠图；重新打开扩展后，可以恢复最近保存的图片。不会自动在其他网页注入图片。
- 弹窗中的「移除图片」同时清除最近保存的图片；网页工具条的 × 只移除当前页面的叠图。卸载扩展会清除本地存储。
- `activeTab`：点击扩展时访问当前标签页。
- `scripting`：向当前网页注入叠图组件。
- `storage`：本地记住透明度、缩放、位置等设置。
- 没有后台服务、远程脚本、统计分析或外部请求；无需所有网站的访问权限。

## 支持范围

- 支持 PNG、JPEG、WebP、GIF、AVIF、BMP，单张文件最大 20 MB。GIF 等动图按浏览器原生方式播放。
- SVG 不在支持范围内，避免设计文件中的外部资源产生网络请求；可先导出为 PNG。
- 使用图片的自然尺寸作为 100% 比例。如果设计稿是 2 倍导出，通常先调到 50%。不同设备像素比和页面缩放也可能影响比对，需要按实际页面调整。
- Chrome 内置页面、新标签页、扩展商店及部分受保护页面禁止注入扩展，请切换到普通网页。
- 对比 `file://` 本地 HTML 时，需要在扩展详情中开启「允许访问文件网址」。localhost 页面无需此设置。
- 叠图位于页面顶层、使用独立 Shadow DOM，但浏览器原生弹窗、全屏元素与 HTML top layer 元素可能显示在它上方。
- 图片锁定后，右下角的扩展工具条仍可点击。隐藏图片可同时隐藏工具条。

## 开发验证

扩展使用 Manifest V3 和原生 JavaScript，没有打包步骤。修改后，在 `chrome://extensions` 点击扩展的重新加载按钮，并刷新目标网页。

本地测试页位于 `tests/fixture.html`，可以启动静态服务器后访问它：

```sh
python3 -m http.server 8765
```

打开 `http://localhost:8765/tests/fixture.html`。检查叠图拖动、透明度、缩放、锁定后点击按钮、滚动模式切换、弹窗重开后恢复状态、移除和刷新后的恢复行为。

自动端到端测试使用 Node.js 22+ 和 Chrome for Testing / Chromium，无需 npm 依赖：

```sh
CHROME_BIN='/你的/Chrome for Testing/可执行文件路径' node tests/smoke.mjs
STRICT_CSP=1 CHROME_BIN='/你的/Chrome for Testing/可执行文件路径' node tests/smoke.mjs
```

脚本启动临时浏览器配置和本地 HTTP 服务，实际加载扩展并操作弹窗、导入图片、拖动、按键及网页按钮，检查本地保存、刷新恢复和删除；完成后自动清理。第二条命令额外验证限制 `img-src 'self'` 的页面。测试不会访问你的日常 Chrome 配置。
